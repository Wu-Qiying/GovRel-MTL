# GovRel-MTL

Code and 2024 Weibo pilot links for JoVE manuscript 75648 (R2).

- `data/` contains 360 post links from six government accounts.
- `govrel/` contains the preprocessing scripts, B7 reference model, and evaluation code.

Run `python -m govrel.check_links` to check the link lists offline. See [USAGE.md](USAGE.md) for input formats and commands. The study workbook and record-level data are kept separately.
